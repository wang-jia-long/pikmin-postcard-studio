☁️連結 Google Drive
Google 登入不能在直接雙擊開啟的網頁（file://）上使用，請改用本機伺服器開啟：
1. 在放這個 HTML 檔的資料夾開啟終端機（命令提示字元），執行 python -m http.server 8000
2. 用 Chrome 開啟 http://localhost:8000/，點這個 HTML 檔。
第一次使用：申請 OAuth 用戶端 ID（約 5 分鐘，只要做一次）
  1. 到 console.cloud.google.com 建立一個專案（名稱隨意）。
  2. 在「API 和服務 → 程式庫」搜尋 Google Drive API，按「啟用」。
  3. 設定 OAuth 同意畫面（新版介面叫 Google Auth Platform）：使用者類型選「外部」，發布狀態保持「測試」，並在「測試使用者」加入你自己的 Gmail。
  4. 到「憑證」（或「用戶端」）→ 建立 OAuth 用戶端 ID，應用程式類型選「網頁應用程式」。
  5. 「已授權的 JavaScript 來源」加入 http://localhost:8000，儲存（可以同時加好幾個網址，例如 GitHub Pages 的網址和 http://localhost:8000）。
  6. 複製產生的用戶端 ID（結尾是 .apps.googleusercontent.com），貼到下面。
登入時 Google 會顯示「這個應用程式未經驗證」，因為是你自己建立的專案，按「繼續」即可。這個工具只會讀取你指定的資料夾，並在裡面建立整理結果。
